Dev Pulse

A real-time developer productivity and telemetry dashboard providing deep insights into coding habits, workflow rhythms, and project metrics.

Flutter Analytics Desktop Telemetry

Overview

  • Real-time telemetry engine tracking coding sessions, keystrokes, and active project time.
  • Rich analytics dashboard with charts, heatmaps, and streak tracking.
