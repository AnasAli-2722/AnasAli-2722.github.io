01. OVERVIEW

What is Dev Pulse?

Dev Pulse is a real-time telemetry engine tracking coding sessions, keystrokes, and active project time. It features a rich analytics dashboard with charts, heatmaps, and streak tracking. Built as a cross-platform desktop application with Flutter, it utilizes a privacy-first architecture where all data is processed and stored locally.

03. KEY FEATURES
